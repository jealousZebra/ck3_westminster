# Contributing

Raise a pull request against `main`. Small fixes can go straight to a PR; discuss new mechanics, starts or major
balance changes in an issue first. Bug reports, translations, DNA improvements and documentation fixes are welcome.

## Workflow

1. Fork the repository and create a branch for your change.
2. Follow [setup](README.md#setup), then use the [modding guide](docs/modding.md) to find the source file.
3. Edit the generator when a file says “Generated by”; commit the source and its regenerated script/localization.
   Keep exported portrait sources too. Generated map/interface textures, downloaded data and test saves stay ignored.
4. Run the checks below. For gameplay/history/UI changes, test the affected start in CK3 and inspect its error log.
5. Open a PR explaining the change, why it helps, and how you tested it. Screenshots help for UI or DNA changes.
   State any checks you could not run; you do not need every DLC or every operating system to contribute.

```sh
python3 common/tools/ck3_checks.py static westminster/westminster
python3 westminster/tools/data/test_character_overrides.py
python3 westminster/tools/data/test_eras.py
python3 westminster/tools/data/test_stability.py
python3 common/tools/check_secrets.py
```

[Engine test instructions](docs/ck3-testing.md) cover fresh campaigns and scripted suites. Automated window-driving
helpers are macOS-specific; manual CK3 testing works on Windows and Linux too. There is no need to rebuild art for a text-only change.

## Conventions

- New CK3 IDs use `wm_`; `rf_` belongs to the test harness. Check for collisions.
- CK3 script/GUI/localization: UTF-8 BOM. Python/JSON/docs: UTF-8. Use British English.
- Add localization keys in all nine supported languages. Clearly identify English fallback text in the PR.
- Keep scripts readable, document their scope, and reuse effects/triggers. Avoid unrelated reformatting.
- Use `common/tools/ck3paths.py` for game/user paths. Never commit credentials, local launchers, saves or crash dumps.
- Real people: use public sources for historical details; events must remain generic and fictional. Do not script
  allegations against named living people. MPs' relatives are invented; the royal family's documented history is separate.
