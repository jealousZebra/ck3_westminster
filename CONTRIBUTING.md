# Contributing

Thanks for helping. This repo holds Westminster, a Crusader Kings III total conversion about modern UK politics.
README.md says how it's built and tested, and ROADMAP.md what's planned.

## Before you start

- Follow the setup in [README.md](README.md#setup).
- Read [docs/ck3-modding-notes.md](docs/ck3-modding-notes.md) before writing CK3 script or GUI. Many of the engine's
  traps fail silently.
- For anything bigger than a fix, open an issue first. Design and UX changes to a mod are discussed before they're
  built.

## Making a change

1. Edit the generators, not their output. Many files in the mod folders are written by scripts in `<mod>/tools/` and
   say so in their first line ("Generated by ... - edit there"). Copies of the game's own files name the game file
   and the script that changes them ("Crusader Kings III's own gui/hud.gui (Paradox Interactive), ... by
   westminster/tools/ui/build_theme.py - edit there"). Re-run the generator after editing it.
2. Run the static checks: `python3 common/tools/ck3_checks.py static <mod>/<mod>`.
3. Run the mod's in-game tests if you can (macOS only, see [docs/ck3-testing.md](docs/ck3-testing.md)), then
   `python3 common/tools/ck3_checks.py errorlog <prefix>` (`wm_`, Westminster's prefix).
4. Keep localization in every language the mod supports. The static check lists missing keys.
5. Describe what you changed and how you tested it in the pull request.

## Conventions

- Every script, GUI and localization file is UTF-8 with a BOM.
- Everything a mod adds starts with its prefix (`rf_`, `wm_`).
- Python: standard library plus `requirements.txt`. Keep game paths behind `common/tools/ck3paths.py`.
- Text is plain British English.

## Real people (Westminster)

Westminster uses real politicians' and royals' names. Events must stay generic and fictional: never a scandal, crime
or claim aimed at a named living person. Invented relatives only, never real ones (the royal family's real
relationships excepted).
